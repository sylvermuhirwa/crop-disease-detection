# Early Crop Disease Detection

Early crop disease detection using machine learning.

**Status:** In progress 🚧

## The problem
Crop diseases spread fast and can destroy a harvest before farmers notice the first signs. Detecting them early can protect yields and the livelihoods of smallholder farmers.

## Goal
Build a machine learning model that identifies crop diseases from leaf images, so problems can be caught and treated early.

## Planned approach
- Collect and clean a labelled dataset of healthy and diseased crop leaves
- Explore the data and check class balance
- Train and compare image classification models
- Evaluate results with accuracy, precision, and recall
- Document findings and how to reproduce them
